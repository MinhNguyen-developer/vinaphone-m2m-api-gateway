# User Intake Template

When the user does not provide enough context, ask them to use this template.

```text
Project name:
Business goal:
Target users:
Main features:
Expected number of users:
Expected traffic:
Data type:
Integrations:
Security/compliance requirements:
Preferred cloud provider:
Preferred tech stack:
Budget level:
Timeline:
Team size:
Current system, if any:
Biggest concerns:
```

## Minimal questions when time is limited

Ask only these if the user wants a fast answer:

1. What is the business goal and target users?
2. What are the must-have features for the first release?
3. What is the expected traffic and data sensitivity?
4. What cloud provider and tech stack does the team already know?
5. What is the timeline, budget level, and team size?

/solutions-architect Project name: Internal AI Knowledge Assistant
Business goal: Help employees search internal policies and operational documents using natural language.
Target users: 1,000 internal employees
Main features: Chatbot, document upload, semantic search, citations, feedback, admin dashboard
Expected number of users: 1,000 employees, around 300 daily active users

Data type: PDF, DOCX, internal policies, SOPs, web pages
Integrations: SSO, SharePoint, Slack
Security/compliance requirements: Role-based access, audit logs, private data protection
Preferred cloud provider: AWS
Preferred tech stack: React, FastAPI, PostgreSQL, Qdrant
Budget level: Medium
Timeline: 3 months
Team size: 5 engineers
Current system: Documents stored in SharePoint
Biggest concerns: Accuracy, security, cost, maintainability
